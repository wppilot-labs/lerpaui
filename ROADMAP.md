# Lerpa UI Roadmap

The official release path for the Lerpa UI ecosystem.

## Version 0.1: Monorepo Foundation & Registry MVP (Current Phase)
- [x] Monorepo workspace configuration using `pnpm`
- [x] Basic design tokens, Tailwind v4, and Motion setup
- [x] Core 15 components built
- [x] Core 15 interactive blocks built
- [x] Initial registry script compiling copy-paste JSON metadata
- [x] Beautiful documentation homepage and components gallery layouts

## Version 0.2: AI & Dashboard Integration
- [ ] Complete AI component ecosystem (RAG source panels, node builders)
- [ ] Premium administrative dashboard layouts using Recharts and TanStack Table
- [ ] Multi-filter searchable documents search indexes
- [ ] Preconfigured custom transition components and hooks
- [ ] CLI setup alpha

## Version 0.3: Ecommerce & Agency Templates
- [ ] Comprehensive Ecommerce sections (product galleries, review sections, filters)
- [ ] Modular Agency showcase components
- [ ] Fully-featured landing page layouts and starters
- [ ] Comprehensive theme variables library

## Version 0.4: Theme Studio & Block Composer
- [ ] Interactive online Theme Studio mapping color codes directly to CSS variables
- [ ] Live page Block Composer compiling selected block sets to copy-paste page components
- [ ] Integrated starter boilerplate boilerplates
- [ ] Advanced performance checklist validation

## Version 1.0: Launch & Community Scale
- [ ] 200+ free animated components, blocks, and templates
- [ ] 25 full site templates covering SaaS, AI, CRM, and store templates
- [ ] Stable CLI and validated package managers integration
- [ ] Full automated keyboard and reader accessibility validation
