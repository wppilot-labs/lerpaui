# Lerpa UI Brand Guidelines

## Product Identity
- **Product Name**: Lerpa UI
- **Tagline**: Free animated React blocks for modern product teams.
- **Main Slogan**: Everything you need to build premium React interfaces — free forever.
- **Secondary Slogan**: Copy it. Customize it. Ship it.

## Design Philosophy
Lerpa UI is built to feel clean, high-tech, premium, and professional. It sits at the intersection of developer-focused simplicity (like `shadcn/ui`) and immersive high-fidelity graphics (like `Aceternity UI` or `Magic UI`).

- **Typography**: Clean, geometric sans-serif fonts are preferred (e.g., `Inter`, `Outfit`, `Geist Sans`). Code displays use modern monospace fonts (e.g., `JetBrains Mono`, `Geist Mono`).
- **Harmonious Palettes**: Avoid flat, basic primary colors. Use deep carbon colors for dark mode backgrounds, crisp white-to-slate transitions for light mode, and high-fidelity accents (e.g., violet neon, emerald glow).
- **Subtle Motion**: Animations should serve readability and interaction feedback. Avoid jarring, heavy-loop animations that degrade page performance.
