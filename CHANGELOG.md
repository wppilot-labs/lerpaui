# Changelog

All notable changes to Lerpa UI will be documented in this file.

## [0.1.0] - 2026-05-21
### Added
- Monorepo structure using `pnpm` workspaces.
- Shared ESLint, TypeScript, and Prettier configurations.
- Design tokens package containing color variables, spacing configurations, radius templates, and shadow designs.
- Core 15 accessibility-validated React components.
- Standard 15 preconfigured interactive blocks with Tailwind CSS v4 and Motion support.
- Fully featured Next.js documentation and marketing website containing homepage layouts, component selectors, and guides.
- CLI package foundations.
- Local registry generator compiling registry JSON items statically.
